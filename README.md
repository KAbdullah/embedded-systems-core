## 🛠️ Projects & Milestones

### 1. CPU Scheduling Algorithms Simulator
* **What it is:** A simulation of various CPU scheduling algorithms to understand how operating systems manage process execution and CPU resource allocation.
* **Key Learnings:** Process control blocks, queue management, algorithm efficiency (FCFS, SJF, Round Robin), and modular C design.

### 2. Memory Management Unit (MMU) Simulator *(Archived)*
* **Status:** Unfinished
* **What happened:** Due to extraneous circumstances over the past two weeks, I was unable to complete the final implementation. While I grasped the core theoretical concepts of virtual memory, paging, and address translation, I have decided to leave this project as-is. 
* **Why move on?** Rather than forcing a completion using template files provided by my professors, I am choosing to pivot toward hands-on embedded systems work. I will build upon my mental model of virtual memory by applying these low-level architectural concepts directly in practice.
